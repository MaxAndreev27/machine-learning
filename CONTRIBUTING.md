# Contributing

Thanks for helping improve this learning repository.

## Before contributing

1. Open an issue for substantial changes or new topics.
2. Keep examples focused, readable, and runnable.
3. Follow the existing chapter and notebook structure.
4. Do not commit virtual environments, generated model files, datasets, secrets, or notebook outputs that are not needed.

## Pull requests

Please include:

- A concise description of the change.
- The chapter or notebook affected.
- Validation performed, such as running the changed notebook or relevant example.
- Any dependency or environment changes.

Keep pull requests small enough to review. Update the README or requirements file when the change affects setup or project usage.

## Commit messages

Use a short imperative subject, for example:

```text
Add model checkpoint example
Fix pandas preprocessing example
```

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
